# 발표 통계 Pandas · 공식 팀 실행본

본 폴더에는 **성원 팀원이 제공한 Pandas 실행용 코드와 발표 시각화 산출물**을 수록했습니다. 기존에 보관했던 Pandas 스크립트 11개는 삭제하고, **팀원의 최종 실행 코드 11개로 교체**했습니다. 두 버전이 동시에 있는 구조가 아닙니다.

> 본문 전체의 데이터는 KREAM 스타일의 **교육용 합성 데이터**입니다. 실제 KREAM의 공식 운영 수치가 아닙니다.

### 실행용 보조 코드

- [`data_loader.py`](코드/data_loader.py): 분석용 CSV 3개를 각 목적에 맞게 로드합니다.
- [`make_visualizations.py`](코드/make_visualizations.py): Pandas 집계 결과를 Matplotlib 그래프·통계표·실행 로그로 저장합니다.
- [`prepare_data.py`](코드/prepare_data.py): 별도 전체 MySQL 출력 CSV·컬럼 사전·기존 수신 코드로부터 분석용 입력을 준비한 과정의 코드입니다. 재사용 시 필수 인자를 확인해야 합니다.
- [`check_outputs.py`](코드/check_outputs.py): 그래프·갤러리 파일의 기본 무결성과 저장된 검증 결과를 확인합니다.

**구분:** 00번 통합본은 01~10번의 별도 추가 분석이 아닙니다. 통계 계산은 Pandas, 그래프 생성은 Matplotlib을 사용합니다. 기존 프로젝트의 `src/verify_team_analysis.py`와 이번 실행본은 목적이 서로 다릅니다.

## 3. 입력 데이터와 다시 실행하는 방법

| 준비물 | 설명 |
| --- | --- |
| 입력 데이터 | [`데이터/분석입력_CSV.zip`](데이터/분석입력_CSV.zip)에 세 CSV 압축 보관 |
| 로컬 실행 안내 | [입력 압축 풀기와 출처](데이터/README.md) |
| 의존성 | [`requirements.txt`](requirements.txt) |
| Windows | [`실행.bat`](실행.bat) |

1. `데이터/분석입력_CSV.zip`의 **CSV 세 개를 `데이터/` 바로 아래로 압축 해제**합니다.
2. Python과 requirements의 패키지를 설치합니다. 그래프 생성에는 시스템 한글 글꼴도 필요합니다.
3. 프로젝트의 `analysis/pandas_presentation/`에서 다음을 실행합니다.

```bash
python -m pip install -r requirements.txt
python 코드/make_visualizations.py
python 코드/check_outputs.py
```

Windows에서는 입력 CSV 압축 해제 후 `실행.bat`으로 그래프를 만들고 갤러리를 열 수도 있습니다. 실행하면 `결과/`의 산출물을 재생성하므로, 생성 시각과 시스템 글꼴에 따라 파일 해시가 달라질 수 있습니다.

**이 패키지는 분석용 입력 사본 3개를 포함**하므로 로컬에서 그래프를 재생성할 수 있습니다. 다만 MySQL Bronze → Silver → Gold 전체 처리 과정을 실행한다는 뜻은 아닙니다. 전체 재현과 검증 범위는 [기존 재현 문서](../../docs/REPRODUCE.md)를 따릅니다.

## 4. 분석 범위 및 해석상의 제한

| 내용 | 팀원 실행본의 범위 |
| --- | --- |
| 일반 검수 | 최종 Silver 중 `REV_NO = 1`, 2022.01~2026.08, 243,454건 |
| 선택된 재검수 | 최종 Silver의 `REV_NO = 2`, 21,656건. 전체 검수 오류율로 확장하지 않음 |
| 현재 검수 상태 | 최종 유효 검수 271,787건 |
| 유효 검수 작업량 | 최초 269,892건 + 재검수 21,656건 = 291,548건 |
| 직원 인원 | 검수원 마스터 2,960명(재직·비재직 포함), 실제 가용 인원이 아님 |
| 부서 | 현재 마스터 소속 기준. 검수 당시 소속 이력으로 해석하지 않음 |
| 배상 위험액 | 원천의 계산 규칙에 따른 산식상 금액. 실제 지급·확정 손실이 아님 |

모든 재검수 기간에 대해 `REV_NO=2`가 일반적으로 충분하다고 주장하는 것은 아닙니다. **이번 제공 입력 데이터에서 재검수 21,656건이 해당 조건과 일치하는 것**을 확인한 결과입니다. 새 데이터로 실행할 때는 조건을 다시 확인해야 합니다.
